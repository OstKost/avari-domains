# Avari Domains

Проверка регистрации домена, сайта, DNS и почтовых настроек. React + TypeScript + Vite и один Go-сервис с SQLite. Папка `Avari Domains Artifact` сохранена как визуальный референс.

## Запуск

```sh
cp .env.example .env
docker compose up --build
```

Откройте http://localhost:8080. SQLite хранится в постоянном Docker volume. `GET /api/health` возвращает состояние сервиса.

Для разработки без Docker запустите `go run .` из `backend/` и `npm install && npm run dev` из `frontend/`. Vite перенаправляет `/api` на порт 8080. Production-сборку из `frontend/dist` Go раздаёт через `STATIC_DIR`.

## Как интерпретировать результат

RDAP 404 или однозначный WHOIS-ответ означает «Вероятно свободен». Только регистратор может подтвердить доступность конкретного имени. Неизвестный ответ, ошибка и таймаут никогда не означают свободный домен. Для поддомена и URL диагностика проверяет hostname, а регистрация — регистрируемый домен по Public Suffix List.

Проверка сайта подключается к публичному IP после DNS-проверки и проверяет каждый редирект. Внутренние и специальные IP блокируются. DNS-запросы отправляются на `DNS_RESOLVER`; регион проверки указывается через `CHECK_REGION`. Результаты кешируются на 5 минут, вероятно свободные на 1 минуту, неизвестные на 30 секунд. История текущего браузера хранится 90 дней в SQLite. Лимит: 10 стартовых запросов, затем 20 в минуту на IP.

Публичные тарифы Porkbun запрашиваются через API при проверке. Если API недоступен, для `.com`, `.net` и `.org` используется проверенный каталог с [официальной страницы Porkbun](https://porkbun.com/products/domains) от 28.09.2026. Каталог также содержит проверенные тарифы [Namecheap](https://www.namecheap.com/domains/) и [Timeweb](https://timeweb.com/ru/services/domains/). Для GoDaddy и REG.RU указаны источники, а неподтверждённые цены оставлены пустыми. Это цены зоны «от» для обычного домена; акции первого года отделены от продления и сравниваются в своей валюте и группе условий. Через семь дней запись помечается устаревшей и исключается из определения минимума. При заданных `PORKBUN_API_KEY` и `PORKBUN_SECRET_API_KEY` выполняется проверка конкретного домена. Покупка происходит на стороне регистратора. Партнёрские ссылки задаются в `.env`.

API описан в [openapi.yaml](openapi.yaml). Тесты: `cd backend && go test ./...`; сборка интерфейса: `cd frontend && npm run build`.

## Публикация

GitHub Actions собирает frontend и backend при push в `main`, затем отправляет архив на VPS и пересобирает Docker Compose. `avari.dev` и `domains.avari.dev` обслуживают это приложение через OpenResty; оно слушает только `127.0.0.1:18080`. При первом запуске deploy-скрипт выпускает общий сертификат Let's Encrypt через HTTP-01. Certbot автоматически продлевает сертификат и перезагружает OpenResty после продления.

Для GitHub Actions добавьте secrets окружения `production`: `VPS_HOST` (`176.53.174.118`), `VPS_USER` (`user`) и `VPS_SSH_KEY` (закрытый ключ, ограниченный на сервере командой `deploy/ci-receive-and-deploy.sh`). Пользователь VPS должен иметь passwordless `sudo` для Docker, OpenResty и Certbot. `PORKBUN_API_KEY` и `PORKBUN_SECRET_API_KEY` остаются необязательными и задаются в `.env` на сервере.
